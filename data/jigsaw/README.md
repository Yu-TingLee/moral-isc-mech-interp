# data/jigsaw/

Put the Jigsaw 2018 **`train.csv`** here. Nothing else in this directory is read.
Download it from the [Toxic Comment Classification Challenge](https://www.kaggle.com/c/jigsaw-toxic-comment-classification-challenge/data).
